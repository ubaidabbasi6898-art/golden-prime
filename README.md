# Golden Prime

Simple premium furniture business website for **Golden Prime** (Islamabad).

## Pages

- Home
- Products (20+ sample pieces)
- Contact
- Cart (simple selection list)

## Stack

Next.js · React · TypeScript · Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes

- Cart uses `localStorage`
- Contact form validates in-browser (no email backend)
- No online payments, accounts or admin dashboard
